# 校務行政與教育議題原型

本 repository 收錄校務行政流程、校園事件處理與教育議題的網頁視覺化原型，主要用於概念驗證與內部討論。

## 目前內容

- `Bullying.html`：霸凌防制相關頁面原型
- `1141215remotecontrol.html`：行政流程改善視覺化原型

## 使用限制

本專案涉及校園事件與行政情境，不應直接作為個案紀錄系統。頁面內容若要正式使用，必須先核對現行法規、校內程序與權責分工。

## 資料安全

- 不得提交當事人、檢舉人、證人或教職員的可識別資料。
- 不得提交訪談紀錄、調查報告、案件編號或內部會議紀錄。
- 範例資料應完全虛構或完成去識別化。
- API 金鑰與帳號憑證不得存放於 repository。

## 後續方向

預計將可公開的教育宣導內容與校內行政原型分開管理，並為正式工具補上法規版本、權限設計與操作紀錄。
